🧾 Prescription Size

Set the exact physical size of your prescription pad. The prescription remains vertical (portrait). There is no fixed preset — you can enter your own width and height.

Custom size is saved automatically for future prescriptions. If Width is greater than Height, the software automatically swaps them so the printed prescription stays portrait. Enter the dimensions of your actual prescription paper in centimetres.

🖨️ Prescription Print Spacing

Set how much blank space must be reserved on your pre-printed prescription before the software prints. All four values are measured from the paper edges.

How it works: the software reserves the Top, Right, Bottom and Left spaces first, then prints the prescription only inside the remaining area. This is useful for pre-printed prescription pads.
